Worked example · GSE66207

From raw counts to an explorer-ready JSON

This page runs the full ibdex-projector pipeline end to end against a real public cohort, GSE66207 (33 colon RNA-seq biopsies: 20 Crohn's disease, 13 non-IBD controls). Every command and every number below is real output, captured by actually running the package against these files — nothing here is hand-written or simulated.

1

Start from two raw input files

A raw counts matrix and a GEO sample metadata sheet, both exactly as downloaded, with no pre-processing:

gse66207_counts.csv · GeneID (Entrez) × 33 samples · 4.0 MB GSE66207_sample_metadata.csv · full GEO metadata, 41 columns

The counts file looks like this (first two rows):

2

Build the metadata columns the package needs

ibdex-projector only needs four columns: a sample ID matching the counts file, a tissue label, and two optional passthrough fields (disease, cohort) that the explorer shows on the patient card. GEO's metadata doesn't come in that shape, so this short script derives it — this is the only hand-written code in the whole walkthrough, everything after this point is the package's own pipeline: 

import pandas as pd

meta = pd.read_csv("GSE66207_sample_metadata.csv")

def map_disease(row):
    d = str(row["char_disease"])
    if "Crohn's Disease" in d:
        return "CD"
    if d.startswith("Normal"):
        return "Control"
    return d

out = pd.DataFrame({
    "sample_id": meta["geo_accession"],
    "tissue": "colon",   # source_name_ch1 is just "Colon" for every sample
    "disease": meta.apply(map_disease, axis=1),
    "cohort": "GSE66207",
})
out.to_csv("gse66207_metadata.csv", index=False)

Result: 20 samples mapped to CD, 13 to Control, all tissue colon.

3

Run the pipeline

From the command line:

ibdex project \
  --counts gse66207_counts.csv \
  --metadata gse66207_metadata.csv \
  --sample-col sample_id \
  --tissue-col tissue \
  --out gse66207_projection.json

or equivalently from Python:

from ibdex_projector.project import project_counts_to_json

project_counts_to_json(
    "gse66207_counts.csv",
    "gse66207_metadata.csv",
    sample_col="sample_id",
    tissue_col="tissue",
    out="gse66207_projection.json",
)

Internally this resolves every Entrez GeneID to an HGNC symbol, converts to log2(CPM + 1), restricts to the frozen 3,000-gene panel, z-scores and clips, encodes with the frozen CVAE, scores pathways, and places each sample onto the reference UMAP layout — the same six steps documented in full in the README's step-by-step walkthrough.

6

Load it into the explorer

Open the explorer, click Upload external JSON, and pick the output file. The 33 GSE66207 samples render alongside the reference cohort as gold star/diamond markers, selectable and filterable exactly like the built-in cohorts.
