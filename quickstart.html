Quick Start

Finding your way around the explorer

A short tour of what's on screen and what each control does — no prior familiarity with the tool assumed.

1

Tissue toggle — Colon / Ileum

Endotypes were discovered separately for colon and ileum samples, since the two tissues have different baseline biology. Switching this toggle changes which axis list, scatter plot, and endotype set you're looking at.

2

Axis selector

Choose which pathway axis (e.g. inflammatory response, TNF-alpha/NF-kB signalling) colours and orders the scatter plot. This changes which patients rise to the top of the ranked list, not the underlying data.

3

2D / 3D scatter

Every point is one sample, positioned by its latent coordinates. Toggle between a flat 2D view and a rotatable 3D view of the same underlying space. Click any point to select that sample.

4

Patient profile panel

Once a sample is selected, this panel shows its full pathway profile. Switch between the Radar tab (a shape you can compare at a glance against typical endotype profiles) and the Heatmap tab (exact values across every axis).

5

Cohort, disease and search filters

Narrow the visible samples by cohort, disease label, or a free-text search on sample ID — useful for focusing on one dataset or following a specific patient.

6

Load external samples

Use the upload button to load a JSON file — for example, output from the ibdex-projector CLI run on your own cohort — and see those samples plotted alongside the reference distribution. This happens entirely in your browser; nothing is uploaded anywhere.

Want the deeper explanation of what each plot is actually showing? See Understanding the Plots.
